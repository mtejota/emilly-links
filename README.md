# Emilly Links

Uma landing page/coleção de links limpa e moderna construída com Vite, React e TypeScript 

---

## 🔎 Sobre o projeto

Emilly Links é um projeto simples e elegante para centralizar links, mostrar informações de contato, e destacar projetos ou redes sociais. Foi criado para ser rápido, acessível e fácil de personalizar — perfeito para usar como página pública de portfólio.

Principais objetivos:
- Apresentação profissional e direta dos seus links e projetos.
- Fácil customização e deploy.
- Excelente base para expandir com seções adicionais (projetos, blog, prints).

---

## ✨ Recursos

- Layout responsivo e minimalista
- Desenvolvido com TypeScript + React
- Estilizado com Tailwind CSS e componentes shadcn-ui
- Hot-reload via Vite para desenvolvimento rápido
- Fácil deploy (compatível com Netlify, Vercel, GitHub Pages, Lovable)

---

## 🧰 Tecnologias

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn-ui

---

## 🚀 Instalação e execução (local)

Siga estes passos para rodar localmente:

```bash
# Clone o repositório
git clone <SEU_GIT_URL>

# Entre na pasta do projeto
cd <SEU_PASTA_DO_PROJETO>

# Instale dependências
npm install

# Rode em modo desenvolvimento (hot-reload)
npm run dev
